# Домашняя работа №1 по C++

Четыре самостоятельные программы. Для каждой задачи есть отдельная папка с `main.cpp`.
Стандарт языка — C++20. Настройки форматирования находятся в `.clang-format`.

| Папка | Задача |
| --- | --- |
| `task_1` | Дневник погоды: среднее, минимум и максимум, количество морозных дней |
| `task_2` | Копилка: таблица команд с указателями на функции, дополнительная команда `inc` |
| `task_3` | Табло объявлений: поле 5 × 10 символов и проверка границ |
| `task_4` | Показания датчиков: динамические массивы через `int***` и общий отчёт через `void*` |

## Сборка

В CLion можно открыть корневой `CMakeLists.txt` и выбрать нужную программу: `task_1`, `task_2`, `task_3` или `task_4`.

Из терминала:

```sh
cmake -S . -B build
cmake --build build
```

Запуск первой программы:

```sh
./build/task_1
```

Если CMake не установлен, отдельную программу можно собрать компилятором:

```sh
mkdir -p build
c++ -std=c++20 task_1/main.cpp -o build/task_1
./build/task_1
```

## Ввод

Для задачи 1 вводится положительное количество дней `N`, затем `N` целых температур.
В задачах 2 и 3 каждая команда вводится с аргументами в отдельной строке.

Для задачи 4 вводятся название здания одним словом (до 31 символа), количество этажей,
комнат на каждом этаже и датчиков в каждой комнате. Все размеры положительные.
Затем вводятся целые показания в порядке: этаж → комната → датчик.

Пример ввода для задачи 4:

```text
MIPT 1 2 2
18 19
21 22
```

Вывод:

```text
Building: MIPT
Room 1 1: 18 19
Room 1 2: 21 22
```
